# decomp

C-like pseudocode from Ghidra, for reading. It is not compiled: the source of truth is the
assembler source in `src/`.

| File | Program |
|---|---|
| `adventure.c` | ADVENTURE: the engine, plus the dead code and the unused Applesoft routines |
| `autoload.c` | AUTO LOAD OBJ: the 1987 loader |

Regenerated by `./build.sh` when `GHIDRA_INSTALL_DIR` points at Ghidra 12.1.x. Function names
and the comment above each function come from `src/`; calls to the inline-operand library are
shown with their operands, e.g. `rt_copy(8, &word_buf, &verb_word)` or
`rt_print("ENTER COMMAND")`. A `#` in a string marks a digit the code patches in at run time.
